# 🎉 Jana's Exam Celebration & Flight Countdown

A high-end, cinematic, interactive celebration website built for Jana to celebrate the end of exams and countdown to her upcoming trip!

## Features
- **Cinematic Pink Aesthetic:** Deep glowing gradients, glassmorphism cards, and floating ambient particles.
- **Exam Completion Celebration:** A vibrant opening banner welcoming her freedom.
- **Live Flight Countdown:** A real-time timer ticking down to her arrival on September 21st, 2026.
- **Interactive Boarding Pass:** A sleek flight pass styling her upcoming journey.
- **Interactive Sweet Notes:** Tap-to-reveal cards with lighthearted, encouraging, and sweet messages.
